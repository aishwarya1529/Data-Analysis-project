# Revenue & Profit Decline Investigation \| Retail Analytics

## Overview

This project analyzes declining profitability using SQL and Power BI.

## Business Problem

-   Why are profits declining?
-   Which categories and channels impact profitability?
-   How do discounts affect profit?

## Tools

-   MySQL
-   Power BI
-   SQL
-   DAX

## Dataset

Customers, Orders, Products, Returns and Calendar.

## Dashboard Features

-   Revenue
-   Profit
-   Profit Margin
-   Orders
-   Average Discount
-   Revenue vs Profit Trend
-   Category-wise Profit Margin
-   Sales Channel Analysis
-   Discount vs Profit Margin
-   Product Profit Analysis

## Key Insights

-   Stable revenue with declining profit.
-   Higher discounts reduced profitability.
-   Marketplace channel had the lowest margin.
-   Loss-making products affected profit.
