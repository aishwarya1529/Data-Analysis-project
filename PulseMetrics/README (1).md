# SaaS User Growth & Engagement Dashboard

## Overview

This Power BI dashboard analyzes user acquisition, engagement, premium
conversion, and revenue performance for a simulated SaaS platform
covering the period from 2024 to 2025.

The objective of this analysis is to identify the key drivers behind
user growth, user engagement, premium conversion, and revenue generation
to support product and business decisions.

------------------------------------------------------------------------

## Dashboard Components

### KPI Cards

-   Total Users
-   Premium Users
-   Total Revenue
-   Premium Conversion %
-   Renewal Rate %

### Visualizations

-   Monthly Active Users (MAU) Trend
-   New User Signups Trend
-   User Acquisition by Channel
-   Conversion Quality by Channel
-   Revenue vs Discount Trend
-   Device Type Distribution

------------------------------------------------------------------------

## Key Insights

-   User acquisition is primarily driven by a few high-performing
    marketing channels.
-   Premium conversion varies significantly across acquisition channels.
-   User signups show a steady upward trend throughout the analysis
    period.
-   Device preferences reveal where users engage with the platform the
    most.
-   Revenue is influenced by discount strategy, highlighting
    opportunities to optimize pricing.
